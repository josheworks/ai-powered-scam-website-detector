About This Project

AI-Powered Scam Website Detection System

This tool analyzes a given URL using multiple safety checks — HTTPS presence, IP-based address detection, and AI-powered content analysis — to produce a trust score and a clear verdict: Safe, Suspicious, or Dangerous.

Tech Stack

  • Frontend: HTML, CSS, JavaScript
  • Backend: Node.js, Express
  • Database: MongoDB
  • AI: Google Gemini API

Project

BCA Mini Project — built to demonstrate practical application of web development and AI integration for cybersecurity awareness.
